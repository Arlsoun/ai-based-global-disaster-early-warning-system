\# AI-Based Global Disaster Early-Warning System



An AI-based disaster risk assessment and early-warning dashboard for analyzing historical global disaster events.



The system combines historical disaster data, risk scoring, machine learning prediction, geographic visualization, interactive filtering, warning indicators, and model evaluation in a Streamlit dashboard.



\## Project Overview



Natural disasters such as floods, storms, and other hazardous events can cause significant damage to communities and infrastructure.



This project analyzes historical disaster-event data and produces risk assessments for individual disaster events.



The system provides:



\- Historical disaster risk scoring

\- Machine learning-based risk prediction

\- Global geographic disaster visualization

\- Interactive dashboard filters

\- High, medium, and low risk indicators

\- Model evaluation metrics

\- Interactive disaster-event data table



\## Objectives



The main objectives are to:



1\. Analyze historical disaster events.

2\. Calculate disaster risk scores.

3\. Train a machine learning model for risk prediction.

4\. Classify disaster events into risk levels.

5\. Visualize disaster events geographically.

6\. Provide interactive filtering.

7\. Present warning indicators for different risk levels.

8\. Evaluate the machine learning model.

9\. Provide a user-friendly dashboard for disaster risk analysis.
